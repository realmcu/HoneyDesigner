# HoneyGUI Design 文档

本目录只保留面向用户和维护者的长期文档，临时实施计划与重复的模块说明不在此维护。

## 文档导航

| 文档 | 适用对象 | 内容 |
|------|----------|------|
| [功能使用手册](./功能使用手册.md) | 设计器用户 | 组件、事件、代码生成、组件树、国际化和快捷键 |
| [开发指南](./开发指南.md) | 项目维护者 | 当前架构、数据流、开发流程、构建、测试与调试 |
| [HML 中文规范](./HML-Spec-zh.md) | HML 作者 | HML 结构、组件、属性、事件和引擎支持矩阵 |
